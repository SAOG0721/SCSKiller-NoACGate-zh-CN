# SCSKiller-NoACGate-zh-CN

这是 [BlueHeisenberg/SCSKiller](https://github.com/BlueHeisenberg/SCSKiller) 的简体中文 fork。它保留 SCSKiller 的着色器预编译功能，并允许用户在看到风险警告后，逐游戏选择是否对检测到反作弊的游戏尝试录制着色器。

`NoACGate` 只表示解除本程序自身的录制门禁。游戏的反作弊仍可能拒绝加载代理 DLL、阻止录制、使游戏无法运行或处罚账号。本 fork 不保证兼容性或账号安全。详细说明见 [中文 README](README.zh-CN.md)，当前工作与验证边界见 [TODO](TODO.md)。
